# WorkBuddy 自然绿液态玻璃前端改版设计

## 目标

把当前“暖白账页”用户网站替换为自然草地、柔光和液态玻璃组成的统一视觉世界，同时保持登录、余额、充值、Key、安装和管理业务逻辑不变。

本次改版覆盖登录页和登录后的用户端。管理后台继续使用现有结构和样式，只共享必要的状态色与可访问性规则，不纳入本次视觉重构。

## 视觉依据

用户提供两张视觉参考：

- 草地风景图决定色彩、光线和整体氛围：浅草绿、薄荷绿、柔和天空青、乳白云层、温暖日光。
- 人物头像图作为个人品牌角色：登录页重点出现，进入应用后只作为侧栏底部的小型头像标记。

界面不是把插画直接铺满所有页面，而是从插画提取色彩和空气感。操作页面保持足够清晰、紧凑和专业。

## 创意方向

创意主题为“风行工作台 / Meadow Glass Workspace”。

登录页像进入一片明亮草地；登录后的工作台像放在草地光线中的半透明控制台。玻璃材质用于划分功能面和强化操作，不用于堆叠装饰。

主要特征：

- 自然绿背景与乳白玻璃面板。
- 深森林绿作为主要操作色。
- 头像只在登录页和侧栏个人区出现。
- 轻柔圆角、透明边缘、内高光和低强度阴影构成液态玻璃感。
- 业务数据保持高对比、紧凑和可快速扫描。

## 页面范围

### 登录页

- 使用草地风景作为全屏背景。
- 人物头像作为主视觉，放在左侧或中央偏左，与背景自然衔接。
- 邮箱验证码登录框位于右侧玻璃面板。
- 登录说明保持简短，不增加未经证实的商业数据、评价或宣传语。
- 小屏幕改为人物与登录框纵向排列，确保输入区域不被背景干扰。

### 用户端应用壳

- 桌面使用窄型玻璃侧栏和弹性内容区。
- 侧栏包含品牌标记、主要导航和底部个人头像。
- 当前导航使用深绿色柔和高亮，不使用大面积纯黑反相。
- 页面内容放在最大宽度容器中，背景插画明显降噪，只保留绿意和光线。
- 平板收窄侧栏；手机改为固定底部导航。

### 控制台首页

- 可用额度和冻结额度使用两张主要玻璃面板。
- 最近生成、最近账本采用紧凑列表，不用巨型标题或大量空白。
- 状态继续用文字、图标、底色共同表达。

### Key 页面

采用用户确认的“双栏工作台”方案。

桌面布局：

- 顶部只保留页面标题、有效 Key 数量和“创建 Key”主按钮。
- 左栏约 280–320px，显示最多 3 个 Key；每项包含名称、公开前缀、状态和最近使用时间。
- 右栏显示当前 Key 详情、完整 Key、复制操作和安装提示词。
- 完整 Key 使用单行紧凑代码区域，内容过长时横向滚动。
- 安装提示词默认展开，正文区域设置高度上限，可滚动并直接复制。
- 重新生成提示词和删除 Key为次级操作，删除仍使用明确危险样式。
- 切换左侧 Key 时在当前页面更新右侧详情，不重新导航。

移动布局：

- 双栏改为上下结构。
- Key 选择区使用紧凑横向选择或纵向列表。
- 选中后显示详情和安装提示词。
- 复制、重新生成和删除按钮满足至少 44px 的触控尺寸。

错误与空状态：

- 没有 Key 时，在紧凑空状态中解释创建后的下一步。
- Release 未就绪时禁止生成安装提示词，并在右栏显示原因和重试按钮。
- 提示词过期时保留 Key，只提示重新生成。
- 复制失败提供可选中文本和明确反馈。
- 删除后自动选择剩余的第一个 Key；没有剩余 Key 时回到空状态。

### 充值与安装页

- 保持既有业务流程和信息顺序。
- 套餐、收款码、凭证上传统一使用玻璃面板与自然绿状态。
- 安装页突出“创建 Key → 复制提示词 → WorkBuddy 执行”三个步骤。
- 手动下载安装器作为备用入口，不与主流程争抢视觉焦点。

## 设计系统

### 色彩

- 背景薄荷：`#dff3d4`
- 玻璃乳白：`rgba(250, 255, 246, 0.68)`
- 深森林绿：`#1f6848`
- 主文字：`#17372b`
- 次级文字：`#537262`
- 柔和边线：`rgba(255, 255, 255, 0.72)`
- 内部分隔：`rgba(48, 105, 73, 0.16)`
- 成功：`#2f7955`
- 待审核：`#8b681e`
- 危险：`#a33f35`
- 键盘焦点：`#245f91`

状态颜色必须同时配合文字或图标，不允许只用颜色区分。

### 材质

主要玻璃面板采用：

- 半透明乳白或浅绿背景。
- 18–24px `backdrop-filter` 模糊。
- 1px 半透明亮边。
- 顶部或左上角内高光。
- 低强度绿色环境阴影。

同一屏幕最多使用三个明显的玻璃层级：应用壳、主要面板、交互按钮。代码框和表格保持更实的浅色底，以保证阅读。

### 圆角与间距

- 页面主面板：24–28px。
- 内容卡与 Key 详情：16–20px。
- 按钮与输入：12–16px。
- 状态标签：完整胶囊形。
- 桌面页面间距以 8px 网格为基础，主要区块间距 24–32px。

### 字体

- 正文与标题继续使用 Manrope Variable。
- Key、任务编号、日期和代码继续使用 JetBrains Mono Variable。
- 页面主标题控制在 36–56px，不再使用占据大半首屏的 100px 级标题。
- 正文最大宽度约 65ch。

### 按钮

- 主按钮使用深森林绿半透明渐变、亮边与内高光。
- 次级按钮使用乳白玻璃面与绿色文字。
- 文本按钮只用于低频操作。
- 危险按钮使用浅红玻璃面和深红文字。
- hover 只增加亮度与轻微上移；active 回落并缩小约 1%。
- 动画持续 150–240ms；减少动态效果偏好下关闭位移和展开动画。

## 响应式规则

- `> 1100px`：完整侧栏，Key 双栏工作台。
- `760–1100px`：窄侧栏，Key 左栏缩至约 240px。
- `< 760px`：底部导航，所有页面单列，Key 选择与详情上下排列。
- `< 420px`：收紧页面边距和玻璃模糊强度，代码区保持可横向滚动。

背景图使用响应式裁切，不让人物头像和重要操作在窄屏重叠。

## 数据与行为边界

- 不修改现有 API、认证、钱包、订单、Key、安装码和安装器协议。
- Key仍然可查看、复制、删除，最多三个有效 Key。
- 安装提示词仍为 30 分钟有效的一次性内容。
- 不在浏览器长期缓存完整 Key 或安装提示词。
- 设计改动不得改变管理员权限和账务逻辑。

## 可访问性

- 所有交互支持键盘导航和清晰的 `:focus-visible`。
- 正文、按钮和状态文字达到足够对比度；背景图上必须有遮罩或玻璃面。
- 图标按钮提供中文可访问名称。
- 提示、成功和错误信息使用可被辅助技术读取的 live region。
- 支持 `prefers-reduced-motion`。

## 验收

- 登录页和用户端形成统一自然绿玻璃视觉。
- 头像在登录页突出，在应用内只作为小型个人标记。
- Key 页面桌面端为双栏，手机端为上下布局。
- Key 页面明显比当前版本紧凑，三个 Key 不造成超长页面。
- 创建、复制、生成提示词、重新生成、删除和错误恢复流程保持可用。
- 桌面和手机截图无溢出、遮挡或低对比文字。
- 长 Key、长提示词、空状态、Release 未就绪和请求失败状态都能正常显示。
- `npm test`、`npm run web:build` 和前端机械设计检查通过。

## 非目标

- 不改造管理后台视觉。
- 不修改后端接口和数据库。
- 不新增网页直接生图。
- 不增加复杂粒子、持续飘叶或视差动画。
- 不改变充值和安装业务步骤。
